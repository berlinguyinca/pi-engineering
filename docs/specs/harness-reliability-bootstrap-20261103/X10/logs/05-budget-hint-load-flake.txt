# Why the file can hang at all, from its own source (lines 40-66, main's file, added by c379a805 / PR #610): the stub
# worker ends with
#     await new Promise<void>((resolve) => {
#       if (req.signal?.aborted) resolve();
#       req.signal?.addEventListener("abort", () => resolve(), { once: true });
#     });
# It resolves only when the runtime aborts the worker. The test's budget is execution_budget_ms: 1000 with
# checkpoint_policy.before_deadline_ms: 200, and node's default per-test timeout is Infinity. So if the budget
# watchdog is starved, the test waits forever and `npm test` never exits -- which is the suite-termination property
# this whole series exists to protect, reached from the opposite side: not a bug in the branch, but a test whose only
# exit condition is a timer that has to win a CPU race.
#
