## What the unit provides
`AgentAction` carries two optional provenance fields, inherited by both trace events (`AgentLoopCandidateEvent`, `AgentLoopPreventedEvent`): `taskProvenance?: TaskProvenance`, a discriminated union of `{ state: "known"; authority; taskId }` (authority is the T01 canonical original-task hash) and `{ state: "unknown"; reason }`; and `modelProvenance?: ModelProvenance` = `{ provider; model; quantization }`. Producers cannot invent shapes because the only constructors are exported pure helpers: `describeTaskProvenance` returns `known` only for `^sha256:[0-9a-f]{64}$` plus a non-empty trimmed task id, and otherwise `unknown` with a reason that distinguishes *missing authority hash*, *missing task id* and *malformed authority hash (want sha256:<64 hex>)* / *(not a string)*; `describeModelProvenance` keeps trimmed strings or `null` and derives quantization with the same `/[-_]quant[-_]([a-z0-9._]+)/i` convention the worker failure seam already uses (`PiWorkerExecutor.ts:2545`); `isKnownTaskProvenance` narrows the union. Absence of a field means "not recorded", distinct from `state: "unknown"` ("recorded as unattributable") — documented on the fields. No producer was wired (`observability.ts`, `workerActivity.ts`, the runtime all deny-listed), so events stay field-free until a later unit emits them.
