## What the unit provides
`deriveTaskAuthority(source)` canonicalizes the **operator-authored** request — trim, drop empty strings, collapse duplicates keeping the first occurrence, preserve authored order (a scope list is a contract, not a set) — and hashes it through the gate's own `canonicalHash` imported from `./resultGate.ts`, so the repo keeps exactly one canonicalization/hashing convention. It refuses with stable reasons instead of inventing placeholders: `goal: empty after trimming`, `scope: empty after canonicalization`, `tests: member 1 is not a string`, `origin: planner-authored content cannot define task authority, expected "operator"`. `derivePlannerContractHash(contract)` is a separate canonical form (`planner-contract/v1`) for the generated artifact, so identical words give different digests and the planner output is recorded rather than ignored. `verifyAuthority(hash, { source, plannerOutput })` recomputes from the frozen operator source **only** — planner content is read to name `diverged` fields and never substituted — and reports `authority mismatch: recomputed … != recorded …` when the recorded hash itself has been tampered with.
