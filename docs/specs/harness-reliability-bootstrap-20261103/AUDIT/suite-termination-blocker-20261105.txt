    await new Promise(resolve => request.signal?.addEventListener('abort', () => resolve(), { once: true }));
    With no signal, or with an abort that never arrives, that promise is unresolvable: the file hangs
    without failing. WorkerRequest.signal is optional (src/workers/WorkerExecutor.ts:143) and

    the file terminates only on the path where the orchestrator hands the run's signal to the worker.
