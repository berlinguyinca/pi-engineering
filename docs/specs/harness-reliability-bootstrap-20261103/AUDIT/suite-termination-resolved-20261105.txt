Causes were two, and the step-2 question in suite-termination-blocker-20261105.txt has a definite answer.
  STEP 2 ANSWER: an operator interrupt DOES reach a parked worker. The stub in mission-interrupt-pause.test.ts
  waits on request.signal; with the allocation defect repaired, the signal aborts, the parked worker returns, the
  mission settles as PAUSED_INFRASTRUCTURE with the task RETRYING and the attempt preserved, and an explicit cancel
  remains the only thing that ends a mission. There is no defect in src/orchestration interrupt/pause propagation and
  nothing was changed there.
  What stopped the worker from ever being dispatched is in src/git/safeGit.ts: see that file's commit
  ("map the shadow out of git output by whole path, not by substring") for the mechanism and its regression tests
  (test/unit/safe-git-shadow-path.test.ts). Reproduced first as a direct call:
    GitRepo.createWorktree(<fixture>, <state dir>, "pi-eng-probe-TSK-a")
    -> Required isolated worktree allocation failed:
       ENOENT: no such file or directory,
       mkdir '/private/private/var/folders/.../safegit/shadow/s-XXXX/.git/pi-engineering-locks'
  Because the rejected promise arrived before runWorker, a test awaiting workerStarted never settled: the file hung
  instead of failing, which is the symptom that artifact recorded.

Still open on macOS, for the next unit of work rather than this PR:
  1. test/orchestration workspace scope: src/orchestration/workspaceManifest.ts refuses an explicit workspace path
     whenever realpath(path) !== path, so any checkout under a symlinked ancestor - every $TMPDIR checkout on macOS -
     is refused as "crosses a symlink boundary". 196 of the 380 remaining whole-suite failures are that one refusal.
     The guard's intent is that a path the user NAMED must not be a link that opens somewhere else; the final
     component is the choice, while an ancestor link is the machine's, and the canonical path is already checked
     against the protected roots afterwards. Narrowing it to the final component is the candidate; it is a security
     boundary, so it needs its own change with the symlink-escape tests (workspace-manifest.test.ts:219, :234) kept.
  2. the same $TMPDIR-vs-/private/var assumption inside the seven safe-git tests named above (test-side expectation,
     after the source-side fix here).
