3. MINOR pathPolicy case folding — rejected
-------------------------------------------
The observation is factually right (anchors are matched case-exactly; `canonicalizeWriteDomain` does not
case-fold) but the implied fix is wrong. Paths in git's index and in manifest allowPaths are case-sensitive
strings; folding them would reject legitimate requests on case-sensitive filesystems (the Linux runners),
which is worse than the aliasing it avoids on case-insensitive APFS. `createPathPolicy` takes the anchor set
from its caller, which derives it from `lstat`/git casing; making the caller's casing consistent with the
manifest's is a caller-side concern, not a reason to weaken the matcher. Recorded, no change.
