# End-to-end acceptance scenarios

1. New UI automatically yields distinct UX hypotheses, diffusion-rendered responsive families, pi-web selection, derived `.ui/`, implementation and validation.
2. Small UI change gets targeted inexpensive evaluation.
3. Mobile regression blocks completion and automatically produces/remediates work.
4. Blind task failure blocks a visually attractive but unusable candidate.
5. Root-cause clustering converts many symptoms into one high-leverage primitive refactor.
6. Multiple worktree candidates receive identical tests and Pareto gates.
7. InferWeave provides independent reviewers or reports insufficient diversity.
8. Idle Pi capacity can safely reduce bounded UI debt without a user command.
9. Diminishing returns stop autonomous churn.
10. Replacing available InferWeave models requires no Pi workflow-code change.
