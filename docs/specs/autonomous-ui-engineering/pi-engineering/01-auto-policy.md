# Automatic UI policy

No slash command or remembered prompt is required.

On repository discovery detect UI presence, framework, routes, components, styling/design system, tokens, startup procedure, browser tests, responsive targets and design docs. Persist capabilities.

Classify every change L0 none / L1 micro / L2 feature-workflow / L3 system-design-system. Backend/API/auth/data changes can be UI-impacting.

Automatically attach proportional UI evaluation. A UI-impacting engineering task is unfinished until its required quality gates pass. Gate failure automatically creates remediation work and continues within configured budgets.
