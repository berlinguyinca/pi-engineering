# Autonomous UI quality controller

This is a persistent orchestration controller, not a callable skill.

Maintain quality state/debt; trigger evaluations; continue remediation after failed gates; use idle capacity for highest-leverage bounded quality debt; create experiments; accept/reject with evidence; preserve history.

Stop on diminishing returns, exhausted budget, excessive disagreement, protected changes or purely subjective preference. Use cooldowns to prevent perpetual redesign churn. All autonomous work is observable, cancellable and reversible.
