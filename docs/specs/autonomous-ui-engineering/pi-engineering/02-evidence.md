# Evidence and deterministic analyzers

Capture synchronized screenshots, optional interaction video, DOM, accessibility tree, bounds, computed styles, route/state, console/network events, performance/layout-shift trace, interaction history, viewport/device/zoom/orientation and source/component mapping.

Measure objectively before asking models: accessibility, contrast, touch targets, overflow, breakpoint failures, token violations, design entropy, duplicated styles/code/components, DOM depth, dead styles, keyboard/focus, refresh/deep links, bundle/performance and runtime errors.

Never use model inference for reliably measurable metrics.
