# Runtime usability and robustness

Canonical tasks are user goals, not click scripts. Measure success, time, actions, navigation depth, wrong turns, backtracks, mis-clicks, errors, latency and assistance.

Blind usability agents receive the live UI and goal without source hints. Autonomous exploration builds the route/control/state interaction graph.

Test first-time/power, keyboard/touch, small/large screen and high-information-load modes. Cover 320/360/390/430 phones, tablets both orientations, laptop/desktop/ultrawide and zoom to 200%.

Exercise long/empty/huge data, loading, backend errors, slow network, reconnect, rapid/repeated clicks, double submit, refresh, deep links, back/forward and modal stacking. Evaluate temporal traces/video, not only final screenshots.
