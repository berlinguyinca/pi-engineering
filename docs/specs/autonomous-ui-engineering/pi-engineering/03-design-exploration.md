# Automatic design exploration

Trigger for new UI, substantial UI surface or major redesign.

1. Analyze product goals, canonical tasks, required information, existing workflows, UI genome and constraints.
2. Request several genuinely different UX architecture hypotheses from InferWeave.
3. Route each through InferWeave to diffusion/image-generation capability.
4. Generate coherent desktop/tablet/phone families plus key pages, dialogs, empty/loading/error states.
5. Check requirements coverage before presentation.
6. In pi-web support Select, More like this, Combine, Feedback, Let Pi choose.
7. Existing apps should include conservative modernization, moderate redesign and clean-sheet candidates when appropriate.
8. Convert selected direction into the versioned UI genome.

Diffusion images are visual ideation/reference, not functional truth.
