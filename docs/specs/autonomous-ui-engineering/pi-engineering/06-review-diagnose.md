# Independent review, diagnosis and specs

Use partially blind roles: visual critic (images/video + goals), usability agent (live app + goal), code critic (source + contract), deterministic analyzers, then diagnosis/architect agents.

Request capabilities and independence from InferWeave, not model names. Preserve confidence and disagreement; investigate large disagreement.

Map findings to DOM, components, styles, files, rules and commits. Cluster root causes and rank by impact, surface, confidence, leverage, expected gain, effort and risk. Generate concrete implementation specs with evidence, invariants, tests, expected metric changes and rollback conditions.
