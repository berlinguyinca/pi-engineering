# Pi Engineering + InferWeave: Autonomous UI Engineering

Implementation specification for automatic UI design exploration, diffusion mockups, evidence-based scoring, remediation, and continuous improvement.

**Pi Engineering owns engineering policy/workflow. InferWeave owns task/capability-based model/runtime selection and execution.**
Pi must request capabilities, not hard-code models. InferWeave must remain compatible with generic elastic GPU workers.

pi-web is an existing external operator UI: integrate it; do not rebuild it. Pi Forge is out of scope.

Core rule: **models propose; evidence and policy determine acceptance.**
