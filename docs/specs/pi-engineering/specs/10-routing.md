# 10 Model routing
Route by role/capability/service class, not GPU. Support discovered Qwen 3.8, GLM-5.3-Flash, DeepSeek, Claude, Codex and future families. Roles include planner, implementer, debugger, tester, reviewer, security, docs, UI/vision, scout and memory workers. Overrides allowed. Fallback preserves capabilities and separation of duties.
