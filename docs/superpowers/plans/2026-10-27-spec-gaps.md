> **For agentic workers:** Use test-driven development and isolated worktrees for each bounded implementation lane.

**Goal:** Close the eight reproducible speed, capability, and functionality gaps found on `53aa50e`.

**Architecture:** Keep existing execution, routing, verification, and artifact boundaries. Enforce contracts at their consuming boundaries, with no new dependencies or live configuration changes. Stack on PR #440 because its reliability fixes are prerequisites.

**Tech Stack:** TypeScript, Node 22, node:test, Biome.

**Spec:** `docs/specs/pi-engineering-runtime-ledger-tournament-spec-v2.md`, `docs/specs/planner-worker-inferweave-contract.md`, `docs/specs/pi-automatic-engineering-lifecycle-model-router-spec.md`, `docs/specs/mission-observability/03-health-stall-and-recovery.md`.

## Constraints and review focus

- Read-only role requests must not gain mutating custom tools; terminal result reporting remains available.
- Missing or malformed completed review output must never authorize promotion.
- Explicit verification requirements remain mandatory when cheap low-risk checks are selected.
- Routing fallback must obey the same eligibility constraints as catalog selection, including refreshed candidate state.
- A wait for one task must not conceal another active worker's stall. Do not introduce mission wall-clock limits.
- Artifact optimization must retain corruption/path/link checks, character-based pagination, and bounded resource use.
- Test commands must preload `test/support/isolatedState.ts`; never use the live agent profile.
